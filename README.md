# AWS Cloud Engineering & Hands-On Labs

Welcome to my **AWS Learning Playbook**! 

This repository is specifically designed for **beginners** who want to start using Amazon Web Services (AWS) from scratch. Every topic here starts with **core, easy-to-understand concepts** and moves straight into **step-by-step hands-on practicals**—complete with real-world troubleshooting notes so you don't get stuck on common beginner errors.

## Why This Repository?
* **Beginner-Friendly:** Written in simple, clear English—no prior cloud experience required.
* **Theory + Practice:** Every lab is divided into two parts:
  1. `README.md` — Simple explanation of core concepts and architecture.
  2. `practical.md` — Copy-pasteable commands, browser verification steps, and common error fixes.
* **Real Troubleshooting:** Includes actual errors faced during setup (such as SSH permission issues, firewall/Security Group blocks, and configuration mistakes) and how to solve them.
